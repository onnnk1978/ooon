# OOON

ブラウザで動くシングルファイルのファンタジーRPGです。

クラシックなRPGに着想を得たルールシステムを採用しています。

## プレイ方法

下記URLへアクセスすることでプレイ可能です。
https://onnnk1978.github.io/ooon/

## 特徴

- **パーティ冒険**：NPCを仲間に加えて最大4人で旅できます
- **世界継承**：キャラクターが引退しても次のPCが同じ世界を引き継ぎます
- **ダンジョン探索**：松明の残量を管理しながら謎と罠を攻略します

## ゲーム内容

### 世界

複数の地方にまたがる20以上の町と集落を旅できます。
また各地方にダンジョンが存在します。松明を持って探索しましょう。

### キャラクター作成

| 選択項目 | 選択肢                             |
| ---- | ------------------------------- |
| 種族   | 人間・エルフ・ドワーフ・ハーフリング・フェアリー・レプラコーン |
| 職業   | 戦士・魔法使い・盗賊                      |

能力値はランダム生成。レベルアップにより成長します。

### 戦闘システム

- 近接・遠距離・魔法の三段階フェーズ制
- パーティ全員が参加する集団戦闘
## 操作

すべてボタンとテキストによる選択式です。マウスまたはタッチ操作でプレイできます。

## セーブ

ブラウザのローカルストレージに自動セーブされます。同じブラウザでプレイを再開できます。
