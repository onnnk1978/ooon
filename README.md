# OOON

クラシックTRPGシステムに影響を受けたテキストベースのブラウザRPG。

## プレイ方法
下記URLへアクセスすることでプレイ可能です。
https://onnnk1978.github.io/ooon/

## 概要

- **構成**: HTML、CSS、JavaScript（ES6+）を1ファイルに統合。
- **UI**: 画面幅860pxを境に、モバイル（1カラム）とデスクトップ（2カラム・左HUD/右ログ）のレイアウトを切り替え。

## ゲームシステム

### 1. キャラクター作成
- **能力値**: ST, IQ, LK, CON, DEX, CHR, SPD（3D6ダイス判定）。
- **種族**: Human, Elf, Dwarf, Halfling, Fairy, Leprechaun（種族ごとに能力値補正あり）。
- **職業**: Warrior, Wizard, Rogue（装備制限、特殊効果、初期呪文習得などの固有仕様あり）。

### 2. 戦闘・探索
- **戦闘**: 攻撃修正値（Adds）、武器ダイス、コンバットレーティング（CR）に基づくターン制処理。CONが0でゲームオーバー。
- **探索**: ダイス（2D6 + 能力値）による能力値テスト。
- **呪文**: Wizard用の各種呪文システム。

## 仕様・データ管理

- **保存**: LocalStorageによるオートセーブおよび複数スロットのセーブデータ管理。
- **バージョン**: 2026062101
